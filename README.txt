DATA SCIENCE LAB DATASET PACKAGE

Set 01 - Set_01_student_dataset.csv
Used for: Python fundamentals, totals, averages, grades and filtering.
Columns: Roll_No, Name, Python, Statistics, Data_Science, Attendance, Total, Average.

Set 02 - Set_02_numpy_matrix.csv
Used for: NumPy matrix operations. A 5x5 integer matrix is provided.
Note: Students may also generate their own random matrix using NumPy.

Set 03 - Set_03_employee_dataset.csv
Used for: Pandas DataFrame, filtering, sorting and groupby.
Columns: Employee_ID, Name, Department, Age, Salary, Experience.

Set 04 - Set_04_messy_student_dataset.csv
Used for: data cleaning and preprocessing.
Contains intentional missing values, duplicate record, inconsistent department labels and invalid values.

Set 05/07/10 - Set_05_07_10_iris_dataset.csv
Used for: EDA, Seaborn visualization, correlation heatmap and KNN/Decision Tree classification.
150 observations, 4 numerical features and 3 species classes.

Set 06 - Set_06_monthly_sales.csv
Used for: Matplotlib line plot, bar chart, quarterly analysis and histogram.
Columns: Month, Sales.

Set 08 - Set_08_exam_scores.csv
Used for: mean, median, mode, variance, standard deviation, quartiles and IQR.

Set 09 - Set_09_study_hours_marks.csv
Used for: covariance, Pearson correlation, scatter plot and hypothesis testing.
Columns: Student_ID, Study_Hours, Marks.

The Iris dataset is the classic Fisher Iris dataset and is available from the UCI Machine Learning Repository.
